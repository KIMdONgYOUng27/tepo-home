- WASD / 방향키 이동, 자동 공격. M으로 마우스 16방향 조준 전환.

- 성장 화면은 보유 장비·17개 누적 능력치·카드별 현재→다음 효과를 함께 표시합니다.

## 한 판의 흐름

출항 → 바다의 약속 선택 → 30분간 전투와 성장 → 승리/패배 결과 → 항구 준비 강화 → 재출항.
30분 생존이 승리 조건입니다. 최종 주요 보스는 29분에 등장하며, 처치 자체가 승리 필수 조건은 아닙니다.
소리·최고 생존 기록·해변 코인·항구 강화는 해당 브라우저의 Godot 저장소에 보관합니다.
항구 강화는 공격력/최대 체력/행운 각 3단계, 비용은 단계별100/200/300코인입니다.

## 성장

기본 무기17종 중6슬롯. 공용 패시브14종 중6슬롯, 지도 유물2종은 별도입니다.
모래탄환/회전 뚝배기/미역 손길/따개비 진주/부두 쇠사슬/조개껍데기/새우깡 부메랑/파도 웨이브/기상이변/몽돌탄/테트라포드 낙하/폭염주의보/흰갈매기/먹갈매기/갈매기 깃탄/갈매기 날갯바람/닻.
몸통치기는 제거했습니다. 시간 정지는 획득 아이템에만 남깁니다.
무기별 개수·탄속·범위·지속 적용은 data/encounters.json의 weapon_profiles와 scripts/arsenal_v7.gd의 실제 계산을 기준으로 합니다.
보유 무기/패시브/유물은 좌측 상단. ESC 수첩에서 모든 조합과 적용 능력치를 스크롤로 확인합니다.
성장·부활은 폭염/광선 합체의 재료로 복귀했습니다. 범용 치명타·골드·저주는 일반 선택 카드에 넣지 않았습니다.
지도 왼고리는 체력/회복, 오른고리는 적 강화를 제공하며 닻 진화에 각각9레벨이 필요합니다.
아이템별 가중치와 보유 장비 우선 검사, 행운에 따른 네 번째 선택지, 중복 없는 후보 추첨이 적용됩니다.
다시 뽑기5회, 건너뛰기5회, 제외5회가 판마다 제공됩니다. 직전 선택지는 즉시 다음 리롤에서 제외됩니다.
강화할 후보가 없으면 체력30 회복 또는25코인을 선택합니다.
바다의 약속은6종 중 중복 없이 시작/11분/21분 보상을 통해 선택하는 특별 강화입니다.

진화는 무기8레벨+대응 패시브1레벨 이상+10분 이후(10분 포함) 등장하는 라운드 보스의 장비 상자가 필요합니다.
5분 보스를 늦게 처치하거나 초반 상자를 10분 이후 열어도 진화 상자로 바뀌지 않습니다.
진화13종과 합체2종의 실제 조합은 data/encounters.json의 evolutions에 정의합니다.
흰갈매기8+먹갈매기8→부산 갈매기떼(이후8레벨 성장).
갈매기 깃탄8+갈매기 날갯바람8+송정 구명튜브→광안리 날개폭풍.
합체는 두 무기를 한 무기로 바꿔 슬롯 하나를 반환하고, 재료 무기의 재등장을 막습니다.
상자 하나에서 최대 한 번 진화/합체하고 나머지 보상은 보유 장비 강화 또는 코인입니다.
파도는 강력 발사체/진화시 관통, 테트라포드는 지점 낙하/진화시 같은 위치 재타격입니다.
폭염은 보스를 제외한 화면의 적을 지우며 기본형은 전리품도 지울 수 있습니다. 장비상자와 유물은 보호합니다.
원작의 구조를 참고한 테포 수치이며 원작 전체 레벨표를 그대로 복제한 것은 아닙니다.

# v0.12 · 배경음 연결

사용자가 제공한 타이틀·일반 전투·후반 전투·보스전 4곡을 웹용 stereo Ogg로 변환했습니다. 약114.8MB의 WAV 원본 대신 총8.98MB의 Ogg를 사용합니다. 원본 WAV는 공개 저장소에 포함하지 않습니다.

타이틀/항구 → 타이틀, 0~10분 → 일반 전투, 10분 이후 → 후반 전투, 살아 있는 주요 보스 → 보스전 우선. 보스를 처치하면 현재 전투 단계로 돌아갑니다. 1.2초 크로스페이드, 반복 재생, 보상/선택/일시정지 중 배경음 감소, 포커스 이탈·전체 뮤트 시 음악 일시정지를 지원합니다. 곡 구성 자체의 완전한 무봉제 루프를 보장하지 않으며 끝단에 짧은 페이드를 적용했습니다.

설정은 배경음·전투 효과음·선택/보상 효과음 3개로 독립 저장됩니다. 브라우저의 첫 사용자 입력 이후 소리가 재생될 수 있습니다. tests/music_checks.gd에서 전환 우선순위·반복·뮤트·포커스·재시작을 검증합니다.

엔진이 프로젝트 형제 tools 폴더에 없으면 GODOT_BIN 환경 변수로 Godot 4.7.2 실행 파일을 지정한 뒤 build.ps1을 실행합니다. 공개 웹은 games/shorekeeper/, 편집용 소스는 game-source/shorekeeper/에 있습니다.
